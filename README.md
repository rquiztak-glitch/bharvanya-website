# Bharvanya E-Suvidha Portal

A responsive bilingual (English/Hindi) static website designed for GitHub Pages.

## Files
- `index.html` — page structure and service content
- `styles.css` — responsive professional styling
- `script.js` — language switch and mobile navigation

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `bharvanya-website` (or another name you prefer).
2. Upload all three files from this folder to the repository's root (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. The site URL will appear on the Pages settings screen.

## Custom domain
If you own `bharvanya.in`, configure it in **Settings → Pages → Custom domain** and follow GitHub's DNS instructions. Do not change DNS until you control the domain registrar account.
